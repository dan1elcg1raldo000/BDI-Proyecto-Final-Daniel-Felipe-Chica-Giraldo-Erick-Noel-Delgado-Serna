# Diccionario de datos PostgreSQL

Extraído del catálogo de la base PostgreSQL ejecutada el 18/11/2026.

## fuente
Identifica la hoja y separa el histórico principal, su auxiliar y las capturas nuevas.

| Columna | Tipo / longitud | Nulo | Default | Restricciones | Negocio |
|---|---|---|---|---|---|
| id | INTEGER / Entero con signo de 32 bits | No | GENERATED BY DEFAULT AS IDENTITY | NOT NULL id; PRIMARY KEY (id) | Identificador interno. |
| hoja | TEXT / Variable; sin límite de negocio adicional al dominio CHECK y al límite del motor | No | Sin DEFAULT | NOT NULL hoja; UNIQUE (hoja) | Nombre único de la hoja o conjunto de captura. |
| archivo_sha256 | TEXT / 64 caracteres (CHECK) | Sí | Sin DEFAULT | CHECK (((archivo_sha256 IS NULL) OR (length(archivo_sha256) = 64))) | Huella del XLSM; NULL en demo/captura. |
| ambito | TEXT / Variable; sin límite de negocio adicional al dominio CHECK y al límite del motor | No | Sin DEFAULT | CHECK ((ambito = ANY (ARRAY['PRINCIPAL'::text, 'AUXILIAR'::text, 'DEMO'::text]))); NOT NULL ambito | PRINCIPAL alimenta indicadores; AUXILIAR se conserva aparte; DEMO se filtra por clase. |

| activa | INTEGER / Entero con signo de 32 bits | No | 1 | CHECK ((activa = ANY (ARRAY[0, 1]))); NOT NULL activa | Indicador operativo 1/0; no borra referencias históricas. |

## turno
Horario del turno. Un turno no identificado permanece NULL.

| Columna | Tipo / longitud | Nulo | Default | Restricciones | Negocio |
|---|---|---|---|---|---|
| id | INTEGER / Entero con signo de 32 bits | No | GENERATED BY DEFAULT AS IDENTITY | NOT NULL id; PRIMARY KEY (id) | Identificador interno. |
| nombre | TEXT / 1 a 40 caracteres (CHECK) | No | Sin DEFAULT | CHECK (((length(nombre) >= 1) AND (length(nombre) <= 40))); NOT NULL nombre; UNIQUE (nombre) | Etiqueta única del catálogo. |
| inicio | TEXT / 5 caracteres (CHECK) | No | Sin DEFAULT | CHECK (((length(inicio) = 5) AND (inicio ~ '^[0-2][0-9]:[0-5][0-9]$'::text) AND (inicio < '24:00'::text))); NOT NULL inicio | Inicio HH:MM. |
| fin | TEXT / 5 caracteres (CHECK) | No | Sin DEFAULT | CHECK (((length(fin) = 5) AND (fin ~ '^[0-2][0-9]:[0-5][0-9]$'::text) AND (fin < '24:00'::text))); NOT NULL fin | Fin HH:MM, con posible cruce de medianoche. |

| id | INTEGER / Entero con signo de 32 bits | No | GENERATED BY DEFAULT AS IDENTITY | NOT NULL id; PRIMARY KEY (id) | Identificador interno. |
| seudonimo | TEXT / 1 a 30 caracteres (CHECK) | No | Sin DEFAULT | CHECK (((length(seudonimo) >= 1) AND (length(seudonimo) <= 30))); NOT NULL seudonimo; UNIQUE (seudonimo) | Alias HMAC irreversible sin la clave privada externa. |
| activa | INTEGER / Entero con signo de 32 bits | No | 1 | CHECK ((activa = ANY (ARRAY[0, 1]))); NOT NULL activa | Indicador operativo 1/0; no borra referencias históricas. |

| Columna | Tipo / longitud | Nulo | Default | Restricciones | Negocio |
|---|---|---|---|---|---|

| Columna | Tipo / longitud | Nulo | Default | Restricciones | Negocio |

| subcodigo | TEXT / 1 a 15 caracteres (CHECK) | No | Sin DEFAULT | CHECK (((length(subcodigo) >= 1) AND (length(subcodigo) <= 15))); NOT NULL subcodigo; PRIMARY KEY (codigo, subcodigo) | Identificador local, conservando variantes históricas. |
| descripcion | TEXT / 1 a 180 caracteres (CHECK) | No | Sin DEFAULT | CHECK (((length(descripcion) >= 1) AND (length(descripcion) <= 180))); NOT NULL descripcion | Descripción única para esa clave de catálogo. |

## registro_produccion
Fila de producción o detalle con sus valores originales, sin propagar cantidades.

| Columna | Tipo / longitud | Nulo | Default | Restricciones | Negocio |
|---|---|---|---|---|---|
| id | INTEGER / Entero con signo de 32 bits | No | GENERATED BY DEFAULT AS IDENTITY | NOT NULL id; PRIMARY KEY (id) | Identificador interno. |
| fecha | DATE / Fecha calendario DATE; no es una cadena de longitud fija | No | Sin DEFAULT | NOT NULL fecha | Fecha registrada en la fuente, ISO AAAA-MM-DD. |
| maquina_id | INTEGER / Entero con signo de 32 bits | No | Sin DEFAULT | NOT NULL maquina_id; FOREIGN KEY (maquina_id) REFERENCES maquina(id) ON UPDATE CASCADE ON DELETE RESTRICT | Línea a la que corresponde la fila. |
| turno_id | INTEGER / Entero con signo de 32 bits | Sí | Sin DEFAULT | FOREIGN KEY (turno_id) REFERENCES turno(id) ON UPDATE CASCADE ON DELETE RESTRICT; CHECK (((estado = 'HISTORICO'::text) OR ((minutos_base > (0)::numeric) AND (minutos_base IS NOT NULL) AND (pacas_reales IS NOT NULL) AND (turno_id IS NOT NULL) AND (referencia_id IS NOT NULL)))) | Turno identificado; NULL significa desconocido o no aplicable según staging. |
| operario_id | INTEGER / Entero con signo de 32 bits | Sí | Sin DEFAULT | FOREIGN KEY (operario_id) REFERENCES persona(id) ON UPDATE CASCADE ON DELETE RESTRICT | Alias de la persona operadora; NULL cuando no se registró. |
| referencia_id | INTEGER / Entero con signo de 32 bits | Sí | Sin DEFAULT | FOREIGN KEY (referencia_id) REFERENCES referencia(id) ON UPDATE CASCADE ON DELETE RESTRICT; CHECK (((estado = 'HISTORICO'::text) OR ((minutos_base > (0)::numeric) AND (minutos_base IS NOT NULL) AND (pacas_reales IS NOT NULL) AND (turno_id IS NOT NULL) AND (referencia_id IS NOT NULL)))) | Presentación del producto; NULL cuando falta. |
| minutos_base | NUMERIC / NUMERIC sin precisión/escala declarada; admite fracciones | Sí | Sin DEFAULT | CHECK (((minutos_base IS NULL) OR ((minutos_base >= (0)::numeric) AND (minutos_base <= (1440)::numeric)))); CHECK (((estado = 'HISTORICO'::text) OR ((minutos_base > (0)::numeric) AND (minutos_base IS NOT NULL) AND (pacas_reales IS NOT NULL) AND (turno_id IS NOT NULL) AND (referencia_id IS NOT NULL)))) | Horas trabajadas del Excel multiplicadas por 60, sin rellenar faltantes. Puede ser 0 en histórico. |
| meta_pacas_hora | NUMERIC / NUMERIC sin precisión/escala declarada; admite fracciones | Sí | Sin DEFAULT | CHECK (((meta_pacas_hora IS NULL) OR (meta_pacas_hora > (0)::numeric))) | Meta de volumen opcional para captura nueva. La fuente histórica no la contiene. |
| pacas_reales | NUMERIC / NUMERIC sin precisión/escala declarada; admite fracciones | Sí | 0 | CHECK (((pacas_reales IS NULL) OR (pacas_reales >= (0)::numeric))); CHECK (((estado = 'HISTORICO'::text) OR ((minutos_base > (0)::numeric) AND (minutos_base IS NOT NULL) AND (pacas_reales IS NOT NULL) AND (turno_id IS NOT NULL) AND (referencia_id IS NOT NULL)))) | Pacas de la fila. NULL se conserva como desconocido, sin copiar datos del registro anterior. |
| origen | TEXT / 1 a 160 caracteres (CHECK) | No | Sin DEFAULT | CHECK (((length(origen) >= 1) AND (length(origen) <= 160))); NOT NULL origen; UNIQUE (origen) | SHA del archivo, fuente y fila; clave idempotente. |
| clase | TEXT / Variable; sin límite de negocio adicional al dominio CHECK y al límite del motor | No | 'REAL'::text | CHECK ((clase = ANY (ARRAY['REAL'::text, 'DEMO'::text]))); NOT NULL clase | REAL para datos del libro o capturas; DEMO para la demostración sintética. |
| creado_en | TIMESTAMP WITH TIME ZONE / Instante con zona horaria (TIMESTAMPTZ) | No | CURRENT_TIMESTAMP | NOT NULL creado_en | Sello UTC de inserción. |
| fuente_id | INTEGER / Entero con signo de 32 bits | No | 4 | FOREIGN KEY (fuente_id) REFERENCES fuente(id) ON UPDATE CASCADE ON DELETE RESTRICT; NOT NULL fuente_id; UNIQUE (fuente_id, fila_fuente) | Hoja/conjunto de origen. |
| fila_fuente | INTEGER / Entero con signo de 32 bits | Sí | Sin DEFAULT | CHECK (((fila_fuente IS NULL) OR (fila_fuente > 0))); UNIQUE (fuente_id, fila_fuente) | Número de fila en la hoja Excel. |
| estado | TEXT / Variable; sin límite de negocio adicional al dominio CHECK y al límite del motor | No | 'CAPTURA'::text | CHECK ((estado = ANY (ARRAY['CAPTURA'::text, 'HISTORICO'::text]))); CHECK (((estado = 'HISTORICO'::text) OR ((minutos_base > (0)::numeric) AND (minutos_base IS NOT NULL) AND (pacas_reales IS NOT NULL) AND (turno_id IS NOT NULL) AND (referencia_id IS NOT NULL)))); NOT NULL estado | HISTORICO conserva anomalías; CAPTURA exige campos y presupuesto de tiempos válidos. |
| minutos_sin_trabajar | NUMERIC / NUMERIC sin precisión/escala declarada; admite fracciones | Sí | Sin DEFAULT | CHECK (((minutos_sin_trabajar IS NULL) OR (minutos_sin_trabajar >= (0)::numeric))) | Horas no trabajadas originales multiplicadas por 60. |

## paro
Tiempo positivo por causa y subcausa de una fila. No equivale a un evento con inicio y fin.

| Columna | Tipo / longitud | Nulo | Default | Restricciones | Negocio |
|---|---|---|---|---|---|
| id | INTEGER / Entero con signo de 32 bits | No | GENERATED BY DEFAULT AS IDENTITY | NOT NULL id; PRIMARY KEY (id) | Identificador interno. |
| registro_id | INTEGER / Entero con signo de 32 bits | No | Sin DEFAULT | NOT NULL registro_id; FOREIGN KEY (registro_id) REFERENCES registro_produccion(id) ON UPDATE CASCADE ON DELETE RESTRICT | Fila de producción de la que depende el detalle. |
| codigo | TEXT / Variable; sin límite de negocio adicional al dominio CHECK y al límite del motor | No | Sin DEFAULT | NOT NULL codigo; FOREIGN KEY (codigo) REFERENCES codigo_paro(codigo) ON UPDATE CASCADE ON DELETE RESTRICT; FOREIGN KEY (codigo, subcodigo) REFERENCES subcodigo_paro(codigo, subcodigo) ON UPDATE CASCADE ON DELETE RESTRICT | Código principal con dos dígitos. |
| subcodigo | TEXT / Variable; sin límite de negocio adicional al dominio CHECK y al límite del motor | Sí | Sin DEFAULT | FOREIGN KEY (codigo, subcodigo) REFERENCES subcodigo_paro(codigo, subcodigo) ON UPDATE CASCADE ON DELETE RESTRICT | Identificador local, conservando variantes históricas. |
| minutos | NUMERIC / NUMERIC sin precisión/escala declarada; admite fracciones | No | Sin DEFAULT | CHECK ((minutos > (0)::numeric)); NOT NULL minutos | Duración en minutos, admite el decimal que aparece en la fuente. |
| observacion | TEXT / Hasta 500 caracteres (CHECK) | Sí | Sin DEFAULT | CHECK (((observacion IS NULL) OR (length(observacion) <= 500))) | Aclaración de nuevas capturas. Las observaciones originales se reservan por privacidad. |
| agente | TEXT / Hasta 60 caracteres (CHECK) | Sí | Sin DEFAULT | CHECK (((agente IS NULL) OR (length(agente) <= 60))) | Grupo que interviene en el ajuste; independiente de si se conoce una persona. |
